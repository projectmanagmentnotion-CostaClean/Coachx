# AthlexForce Media Art Direction

This document captures the usable delta from the Slice 25 Stitch references without adopting prototype tokens or prototype implementation patterns.

## Canonical Direction

- dark
- minimal
- precise
- premium
- athletic
- disciplined
- cinematic

## Brand Tokens

Use the canonical AthlexForce palette only:

- background: `#050505`
- primary surface: `#121212`
- elevated: `#181818`
- secondary surface: `#1A1A1A`
- accent: `#B6FF00`
- secondary accent: `#CAFF4A`
- text: `#F7F7F7`
- warning: `#FFB020`
- error: `#FF4D4F`

## What to Keep

- Strong visual hierarchy.
- Quiet borders and layered surfaces.
- Premium athletic imagery when a real approved asset exists.
- Branded fallback surfaces when it does not.
- Clean crop discipline on mobile widths.

## What to Avoid

- Prototype olive palette drift.
- Temporary Googleusercontent imagery.
- Stock-photo style food assets with no product approval.
- Text overlays that create a second design language inside the image.
- Decorative image treatment that competes with the screen copy.

## Exercise Media Direction

- The workout and exercise surfaces should feel decisive and athletic.
- Media should support the training narrative, not dominate it.
- START / END toggles should remain semantically clear.
- Fullscreen should feel like an extension of the same exercise, not a separate product.

## Meal Media Direction

- Meal imagery should remain calm and informative.
- The fallback should still feel intentional and premium.
- Meal cards and detail sheets should not become a generic food-gallery layout.

## Motion and Layout

- Keep media transitions fast and restrained.
- Never let image loading change the surrounding hierarchy.
- Use safe crop rules instead of moving text into the image surface.

## Relationship to Stitch

- Stitch is art direction only.
- Production code must remain governed by the canonical design and motion systems.
- Prototype defects are not approved.
