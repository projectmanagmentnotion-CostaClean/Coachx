# Motivational Motion Rules

## Purpose

Motion in the immersive progress system should reinforce real progress without becoming a distraction.

## Rules

- Animate only when the data changes.
- Keep transitions short and controlled.
- Use warm motion for close and achieved states.
- Keep calm states visually stable.
- Respect reduced motion at all times.
- Never use motion to fake urgency.

## Allowed Motion

- Progress ring fill
- Small spark burst on real achievement
- Chart line reveal
- Target chip emphasis

## Disallowed Motion

- Flashing attention loops
- Pulsing without a data change
- Celebration without a real milestone
- Any motion that blocks reading or navigation

## Accessibility

- Reduced-motion users get a static but clear representation.
- Focus states stay visible.
- Motion cannot replace text labels.
