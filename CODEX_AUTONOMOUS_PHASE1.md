# COACHX Autonomous Phase 1

## Goal

Implement the current COACHX foundation from Stitch without redesigning the product.

## Active scope

- Today dashboard
- Calendar
- Day detail
- Progress
- Profile
- Shared design tokens and primitives
- Mock data layer
- GSAP motion layer

## Not in scope

- Production Supabase wiring
- OpenAI coaching logic
- Apple Health / Watch integrations
- New product flows not defined in Stitch or roadmap

## Operating rules

- Stitch renderings win for implemented screens.
- Keep the UI mobile-first at the 390px reference width.
- Reuse existing components and assets when available.
- Document any unavoidable differences.
